# sietcompition

A modern, responsive institutional website for **SIET Panchkula** (React + Vite).

## Highlights
- Bilingual UI (English/Hindi)
- Chatbot assistant (rule-based)
- Notice/announcement system
- Dashboard views (student/faculty)
- Accessibility controls (dark mode, font size, contrast)

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
